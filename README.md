# Zync — Website giới thiệu

Landing page cho app Zync (giao việc bằng giọng nói cho micro-team), có radar 3D (Three.js), trang Chính sách quyền riêng tư và Điều khoản sử dụng.

- `index.html` — trang chủ
- `privacy.html` — Chính sách quyền riêng tư (dùng cho Google Play / App Store)
- `terms.html` — Điều khoản sử dụng
- `radar.js` — hiệu ứng radar 3D
- `assets/` — icon + ảnh màn hình

Chạy local: mở `index.html` bằng trình duyệt, hoặc `python3 -m http.server`.
Xuất bản qua GitHub Pages (nhánh `main`, thư mục gốc).
